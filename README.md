# vLLM-HUST SliceGPT

Owner-maintained extraction of the SliceGPT work preserved in the archived
vLLM-HUST and vLLM-Ascend-HUST repositories.

**Status: migration scaffold. This repository does not yet contain an
installable or runnable release.**

The target has two explicit deliverables:

1. an offline conversion and calibration toolkit;
2. a serving-time model-loader/runtime extension for validated SliceGPT
   artifacts.

The artifact schema is versioned and validated before runtime activation.

See [PROVENANCE.md](PROVENANCE.md) and [MAINTAINERS.md](MAINTAINERS.md).
